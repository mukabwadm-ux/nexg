# Demo merchant photographs

Placeholder imagery for the demo merchants in `supabase/demo-data.sql`.
Every file is public domain (CC0 or Public Domain Mark), so none carries an
attribution requirement — the provenance below is recorded so that can be
shown rather than asserted.

These are not photographs of real NexG merchants and must be removed with the
demo data before the site carries real traffic. See `supabase/demo-data-remove.sql`.
