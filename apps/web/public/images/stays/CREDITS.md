# Sample stay photographs

Used only on the **sample listings**, the demonstration properties that show
guests and hosts what a NexG stay looks like. They are marked "Sample listing"
everywhere they appear and cannot be booked (`property.is_sample`). They are
not photographs of any real NexG property, and must never be attached to a
real host's unit.

Every file is CC0 1.0 (public domain dedication), fetched at web size through
Openverse, so none carries an attribution requirement. The provenance below is
recorded so that can be shown rather than asserted.
