# Availability concept images

Exactly three generated desktop screen concepts using the shared NEXG visual style. These are static pictures, not an implemented frontend. The detailed plan governs exact behaviour and timing.

1. [Hours and intake](01-hours-intake.png) — separate location/delivery/collection states.
2. [Appointments and resources](02-appointments-resources.png) — joint staff/room hold and reservation-fee prerequisite.
3. [Assets and exceptions](03-assets-exceptions.png) — overdue return, unknown source and maintenance impact.

Review detail and file hashes: [image manifest](../image-manifest.json). The rental timeline is illustrative rather than pixel-accurate: in implementation, actual custody ends at the current snapshot and its uncertain future continuation begins there.

Original generated files are retained in the default generated_images folder.
