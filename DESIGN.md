# Merchant workspace

Surface mode: Operate. This direction applies to the merchant workspace and Insights; the public website retains its existing design.

The user's compact reference controls placement. Preserve the sidebar navigation styling and replace its NEXG wordmark position with the existing Merchant workspace / Business workspace identity. Do not add another identity block below it.

Desktop Insights is a single viewport composition: compact heading and filters, peer tabs, metric row, chart row, and summary table. The page must not scroll. Fit table rows to the available height and paginate remaining records; preserve full evidence and exports. Work keeps its heading and filters fixed while only its queue scrolls. Tables share soft boundaries and scrollbars that reveal on interaction and fade when idle.

Use NEXG's black navigation, warm cream canvas and restrained gold actions. Keep the Manrope typeface, compact hierarchy, clear borders, 44px controls and shared page rhythm. Nellavio informs the workspace shell, navigation, search, spacing and responsive behavior. NEXG owns the visual identity, terminology, permissions and data model.

Insights keeps Overview and Reports as permanent peers. Middle views adapt to configured merchant activities and permitted sources. Restaurant peers are Orders, Menu, Customers, Operations, Promotions and Finance. Overflow uses More on intermediate widths and a labeled business-area selector on phones.

Every number must have a definition, date basis, unit and contributing evidence. Filters apply to the metric, report and CSV together. Distinguish unavailable evidence from zero. Sample records must be explicitly labeled and must never substitute for a failed live source.

Reuse the existing UI package for tables, detail panels and primitives. Provide table alternatives to charts, keyboard access, visible focus, honest error states and a mobile composition that preserves readable values.

Preserve Promotions' established Campaigns and History navigation. Settings reports device-local preferences honestly; connected service controls must reflect implemented capabilities.
